# 医析台 MedBench

## 一、软件简介

医析台是一款面向临床科研与科室质控场景的**本地化 Excel 数据分析工具**，主要能力：

- **总览与洞察**：数据概况与质量指标、结构画像与推荐分析，以及可选的 **AI 分析建议（解读 + 方案）与探索性分析**
- **数据准备**：表格结构诊断与整理、变量类型手工指定、宽表转长表、缺失模式与多重插补、**多表（每个维度一张表）关系识别与关联**、撤销上一步，以及当前数据的**查看 / 筛选 / 脱敏导出**
- **数据接入**：多 Sheet、表头行 / 大标题行识别、合并单元格填充
- **描述性分析**：数值 / 分类描述统计、正态性检验、常用图表
- **统计推断**：组间比较、配对比较、**相关分析**、诊断一致性（Kappa / ICC / Bland-Altman）、**多重比较校正（FDR / Tukey HSD）**
- **时间与质控**：率的置信区间、感染密度（‰）、SPC 控制图、趋势检验、同比环比
- **预测建模**：**多重线性回归（连续结局，含 VIF / Durbin-Watson / 残差诊断 / 异常点）**、Logistic 回归、Cox 生存回归、ROC / 校准曲线 / 决策曲线 / 列线图、LASSO 变量筛选与 Bootstrap 内部验证、剂量-反应关系（限制性立方样条）、**最佳截断值**、**外部验证**、**纵向重复测量（LMM / GEE）**、**时间序列预测**
- **因果推断与论文辅助**：倾向性评分匹配（PSM）、逆概率加权（IPTW）、亚组分析与森林图、敏感性分析与 E-value、**Table 1 基线特征表自动化**
- **报告导出**：一键导出 Word 分析报告，可选 **AI 审阅与 AI 写作**

**统计计算全部在本机完成**。程序只监听本机地址 `127.0.0.1`，并已关闭 Streamlit 匿名使用统计，统计部分不会向网络上传任何内容。

**关于 AI（可选，默认关闭）**：启用后，仅把**数据结构摘要**（字段名、类型、唯一值数、缺失率、结构角色）发送到你自己配置的 AI 服务，用于解读数据、设计分析方案、审阅结果与写作；**不会发送任何个体数据行，也不会发送均值 / 频数等数值统计**，发送前可逐字预览。启用 AI 后即不再满足「数据零外传」，请按所在机构的数据管理规定决定是否使用。

## 二、启动软件

双击根目录中的：

`医析台.exe`

程序启动后会自动打开浏览器页面，默认地址为：

`http://127.0.0.1:8501`

说明：

- 首次启动需要解包与加载科学计算库，通常等待 30–60 秒；如未自动打开浏览器，可手动访问上面的地址
- **如果 8501 端口已被占用**（例如上一个实例还在后台运行），程序会自动改用 8502、8503…，并把实际地址写入 `%USERPROFILE%\医析台端口.txt`。双击 exe 时若检测到已有实例在运行，程序会直接提示并复用该实例，不会「双击没反应」
- 程序**只监听 127.0.0.1**，因此局域网内其他电脑无法访问，也不会再触发 Windows 防火墙的「是否允许访问网络」提示
- 关闭软件：关闭浏览器页面即可；如程序仍在后台运行，可在任务管理器中结束「医析台」进程

## 三、推荐使用流程

1. 准备 Excel 数据文件。
2. 上传 `.xlsx` 或 `.xls` 文件。
3. 文件包含多个 Sheet 时，在侧边栏选择目标 Sheet。
4. 展开侧边栏「⚙️ 导入设置（表头 / 大标题行）」：
   - **表头行数**：1 = 首行是字段名；2 = 前两行合并成字段名（多级表头）；0 = 无表头
   - **跳过开头行数**：报表顶部大标题（如「XX年度科室报表」）的行数
   - **合并单元格向下填充**：纵向合并单元格读入后为空白，勾选后沿用上一行
   - 勾选「预览前 8 行」确认列名是否正确
5. 打开「📊 总览与洞察」看数据概况；需要改数据时到「🧹 数据准备」页，展开
   「🏷️ 变量类型调整」「🧩 宽表转长表」「🩹 缺失模式与多重插补」等区块处理；
   回到首页看「识别到的结构」与「推荐分析」，用「打开 →」直接跳转到对应页面
   （调整类型或转长表后，画像与推荐会自动重算）。
6. （可选）如需 AI 辅助：在侧边栏展开「🤖 AI 解读」，填入服务地址与模型名，点「🔌 测试连接」确认可用；
   之后可在「📊 总览与洞察」获取 AI 分析建议（填不填研究问题都可以），在「📄 报告导出」让 AI 审阅结果、撰写论文段落。
   未配置也不影响任何本地功能。
7. 依次做描述性分析、统计推断、时间与质控、预测建模等分析。
8. 在「📄 报告导出」中导出 Word 报告。
9. 需要留档或交给同事复核时，在侧边栏「💾 项目」中保存项目文件（`.mda`），以后可直接打开继续分析。

## 四、数据要求

### Excel 结构

- 第一行应为字段名（若第一行是合并单元格大标题，用「导入设置 → 跳过开头行数」处理）。
- 每一行代表一条病例或一个观测样本。
- 每一列代表一个变量。
- 建议不要合并单元格；如有，勾选「合并单元格向下填充」。
- 空白单元格会被识别为缺失值。
- 日期字段建议使用 Excel 日期格式，或使用包含「日期、时间、入院、出院、手术、随访」等含义的字段名。

### 常见变量类型

| 类型       | 示例                         | 用途                     |
| ---------- | ---------------------------- | ------------------------ |
| 数值变量   | 年龄、体重、住院天数         | 描述统计、组间比较、回归 |
| 分类变量   | 性别、治疗组、病理类型       | 分组、卡方检验、亚组分析 |
| 二分类变量 | 是否死亡、是否复发、0/1 结局 | Logistic、PSM、ROC       |
| 日期变量   | 入院日期、随访日期           | 时间维度识别与趋势分析   |
| 文本变量   | 备注、诊断描述               | 数据摘录和关键词筛选     |

### 两种常见的数据形态

| 形态 | 特征 | 处理方式 |
| ---- | ---- | -------- |
| 分析型表（推荐） | 一行一个样本，一列一个变量 | 可直接分析 |
| 报表型宽表 | 指标在行上、时间（1月…12月 / 季度）在列上 | 先用「🧩 宽表转长表」折叠成「时间–数值」两列，再做趋势 / 控制图 |

## 五、功能说明

### 1. 📊 总览与洞察

导入数据后的首页，按「先看数据 → 修数据 → 决定分析」的顺序组织：

**数据概况**：样本量、变量数、缺失率、重复行，以及数值 / 分类 / 二分类 / 日期 / 文本各类型字段数量。

**数据准备**：已移到独立的「🧹 数据准备」页（见下一节）—— 那些操作是「动手改数据」，与首页「看结论、拿建议」不是一回事，混在一起时首页要点开很多区块才能找到东西。

**识别到的结构**：标识列、时间字段 / 宽表时间列、分组变量、二分类结局候选、计数型指标、率 / 密度型指标、指标名维度列、随访时间、配对列，每类都给出判据（字段类型、取值个数、列名语义），并汇总时间维度、分组变量、数值变量、结局候选的数量。

**AI 分析建议（可选）**：配置好 AI 服务后出现该区块（未配置时只显示一行提示，不影响其它功能）：

- **一个入口，按输入自动分流**：填写「研究问题」→ 输出针对该问题的方案（能否做、方法路线、前提检查清单、变量与数据准备、解读口径、可直接使用的方法学段落）；**留空也可以** → 输出「这是什么数据、现在能做什么、暂时做不了什么、数据质量与改造建议、建议的第一步」
- 之所以合并为一个入口：这两件事原本是两个按钮（「让 AI 解读」与「让 AI 设计方案」），但输出的机器可读清单完全同构、下游的规则引擎对照与一键配置也完全共用，真正的差别只是**你有没有提出研究问题** —— 那是输入差异，不该让你去判断该点哪个
- 可**逐字预览将发送的全部内容**（所见即所发）、下载请求 JSON，并可一键「📥 加入报告」
- 结果下方的每条建议都可**一键配置**（跳到对应页签并预填变量，由你点运行），也可**交给探索分析**继续往下做
- 隐私边界与配置方法见「9. 🤖 AI 助手」

**推荐分析（按数据支持度）**：每条都写明判据，可做时给「打开 →」直接跳转；下方列出「暂时做不了的分析」及缺少的条件。

**折叠区**：

- 📋 字段元数据：逐字段的有效样本、缺失率、唯一值、异常值数量（数值字段默认用 IQR 法识别异常值）
- 🧭 更进阶的方法：**仍未内置**的方法（竞争风险、时间依赖 AUC / NRI / IDI 等），并标注当前数据结构是否已满足

在「数据准备」中调整类型或转长表后，结构画像与推荐分析会自动重算。

### 2. 🧹 数据准备

这一页专管**动手改数据**：原先这些内容挤在首页的 7 个折叠区里，与「看结论、拿建议」混在一起，首页要点开很多区块才能找到东西。展开相应区块即可使用：

- **🩺 表格结构诊断（AI，可选）**：当表格「不合规」时（顶部有合并大标题、指标名在行上、时间在列上、末尾有备注行），导入后变量会全部错位、分析页没有可选项。这里让 AI 判断排版结构并给出**可执行的整理步骤**：
  - 默认只发送**单元格类型骨架**（文本 / 数字 / 日期 / 空），**不含任何真实值**
  - 勾选「同时发送前 8 行原样内容」可识别单位行、缺失标记等细节，但会发送单元格内容（字段名自动脱敏）—— **表格含身份证号、手机号等隐私时请勿勾选**
  - AI 给出的是操作清单（跳过行 / 表头行数 / 宽表转长表 / 删行 / 删列 / 重命名 / 指定类型），每条都附上理由；**勾选要执行的那些，再点一次下方的「应用」按钮**（可多选，也可以只勾一条），不会自动执行
  - 操作分两类：「读取设置」类会重新解析原始文件（需数据来自 Excel 上传）；「数据变换」类直接作用于当前数据。请按 AI 给出的顺序应用
  - AI 编造的列名、非法参数会被校验拦下并明确列出，不会静默执行
  - 整理完成后回到本页看「识别到的结构」与「推荐分析」，再决定分析方法
- **↩️ 回到上一步（撤销整理 / 清洗 / 类型改动）**：改了变量类型、整理了表格、做了清洗或插补之后，如果结果不理想，可以退回之前的状态。**数据、人工类型指定与导入设置会一起回退**（只回退数据不回退设置的话，下一次刷新会立刻按旧设置重新算一遍，撤销等于没做）。
  - 最多可回退 8 步，界面会显示「可回退 N 步」与最近一步撤销的是什么操作
  - 换数据（重新上传、切换 Sheet）之前也会自动存一个回退点，误传文件或选错 Sheet 时可以退回
  - 分析类操作是只读的，不需要回退，因此不计入历史
  - 每层回退点都是一份完整的数据副本，因此界面会显示占用的内存；数据很大时建议及时清空历史
- **🔁 整理后评估与下一步（AI 闭环）**：整理之后数据变了，之前的结构建议未必还适用。这一区块把**整理后的摘要**与**整理动作历史**重新交给 AI，评估这份数据现在够不够支撑分析，并给出**建议的第一步**：
  - 列出已执行的整理步骤（含动作、参数、执行前规模与当初的理由），可随时清空记录
  - AI 输出四件事：**数据状态判断**、**建议的第一步**（页签 + 需要选的变量 + 理由）、现在可做的分析、仍需补的条件
  - 若 AI 认为还需继续整理，会直接给出可执行的操作，仍然逐条确认后应用 —— 应用完可再评估，形成迭代
  - 勾选「以后每次应用整理后自动评估」可省去手动点击（每次会消耗一次 AI 调用，默认关闭）
  - 仍然只发送结构摘要与整理动作记录，**不含任何个体数据行与数值统计**
- **✅ 整理建议可多选批量执行**：结构诊断给出的建议每条前都有勾选框，勾选后底部出现
  「按顺序应用选中的 N 项」，一次执行完；也可以只应用其中一条。
  **注意执行顺序**：界面上「读取设置」类（跳过行 / 表头行数 / 合并填充）一定先于
  「数据变换」类执行 —— 前者要重新解析原始文件，不然后者会作用在旧数据上。
  每条的执行结果都会列出，某条失败（例如引用了已被上一条删掉的列）会说明原因并跳过，
  其余照常执行，不会整批中止
- **🔗 多表分析（一个 Excel 里每个维度一张表）**：临床数据常见的形态是「基本信息 / 检验指标 / 用药记录 / 结局各占一个工作表」，靠住院号对应。这类数据**不能直接拼在一起** —— 一个对象多行的那张表会让行数成倍膨胀、样本量虚增，而且拼完从表面完全看不出来。这一区块：
  - **先由本地规则给出结构判断**：每张表的规模与量级（对象级 / 明细级）、疑似主键、疑似时间列，以及表与表之间的关系（按哪列关联、1:1 还是 1:N、能否直接挂接）
  - **再由 AI 判断这批数据能做什么**：这是什么研究场景、表与表该怎么关联（含具体聚合方式与临床理由）、现在能回答哪些研究问题、**建议的第一步**
  - **执行前有三道校验**：① 关联列两边都要有；② 一个对象多行的表**必须给出聚合方式**才允许挂接（即使 AI 声称是 1:1 也会被挡住）；③ **挂接后行数必须与主表一致** —— 一旦变多就说明还有未处理的重复键，程序宁可报错也不产出样本量虚增的数据
  - 聚合方式由 AI 建议，但**是否合适需要你按临床意义确认**：检验指标取峰值、取入 ICU 首次值还是第 3 天值，是研究设计决定的，程序替不了
  - 若某张表更适合**保留全部记录做重复测量**（LMM / GEE）而不是聚合，AI 会单独指出，不会一律压成一行
  - 只发送表结构（字段名、类型、唯一值数、缺失率）与关系判断，**不含任何个体数据行与数值统计**
  - 工作簿只有 1 个工作表、或当前数据来自示例 / 项目文件 / 表格整理结果时，这一区块会说明原因并跳过
- **🏷️ 变量类型调整**：自动识别不准时手工指定（数值 / 分类 / 二分类 / 日期 / 文本）。指定为「数值」后，程序会剥离单位（人、%、个月）与全角字符再按数值处理
- **🧩 宽表转长表**：把「1月…12月 / Q1 / 2024年」这类横向铺开的列折叠成「名称 + 数值」两列
- **🩹 缺失模式与多重插补**：逐字段缺失率表、缺失模式表（哪些字段同时缺失）、缺失矩阵图与缺失率条形图；处理方式包括单值填补（数值列中位数 / 均值，分类列众数）与**多重插补（MICE）**——以列均值为起点、逐列用其余列做线性回归并加残差扰动，生成 m 份插补数据，再用 Rubin 规则合并均值估计（含标准误、95%CI、缺失信息比例 FMI）。插补结果可一键设为当前数据，建议与原始数据分别分析做敏感性对比
- 侧边栏「🧹 数据清洗」：异常值策略 `keep（保留）` / `winsorize（缩尾）` / `drop（删除）`，只在当前会话生效，不改写原始 Excel

- **当前数据的查看 / 筛选 / 导出**（原「📌 数据摘录」页）：选择字段、按范围（数值）或关键词（文本）筛选、限制行数，预览后导出 UTF-8 BOM 编码的 CSV（Excel 可直接打开中文不乱码）。不改动原始数据。

改动数据后结构画像与推荐分析会自动重算；每次改动都会记入撤销历史，「↩️ 回到上一步」可退回（包括「应用清洗」）。


**🔒 脱敏设置（导出前可选）**：展开「🔒 脱敏设置」后，程序会自动识别疑似身份信息字段（姓名、身份证 / 证件号、住址、电话、各类编号等），可对选中的字段应用以下方式：

| 方式 | 效果 | 适用场景 |
| ---- | ---- | -------- |
| 掩码 | 张三丰 → 张\*丰；身份证号只留前 3 位 | 需要保留一定可读性 |
| 稳定假名 | 同一原值映射为同一代号（如 P3F2A…） | 需跨行追踪同一患者 |
| 年龄段 | 45 → 41–65 | 保留年龄的分析价值 |
| 仅保留年份 | 2024-03-15 → 2024 | 日期类字段 |
| 删除 | 整列移除 | 该字段不参与分析 |

可先「👁️ 预览脱敏结果」再导出，下载文件名会标注「已脱敏」。脱敏只作用于导出的文件，**不改动当前会话中的数据**。

### 3. ⏱️ 时间与质控

包含三个子页（原「重复测量 LMM / GEE」与「时间序列预测」已移到「🤖 预测建模」——它们是建模方法，与质控不是一类）：

- **率与置信区间**：指定分子列与分母列；分母为「例数」时计算率（Wilson / Clopper-Pearson / Wald 置信区间），分母为「暴露量」时计算密度（‰，Poisson 精确 CI）；选分组变量后给出各分组率与两组比较（率差、率比 RR 及 95%CI、卡方或 Fisher 检验）。若两列还没选成正确的分子 / 分母，程序会提示「分子合计应小于分母合计」而不是报错
- **SPC 控制图**：自动选择 I-MR（个体值）、P 图（率）、U 图（密度）；判异规则包含单点超 3σ、连续 8 点同侧、连续 6 点递增 / 递减、连续 3 点中 2 点超 2σ；越界点标红并列出信号表
- **趋势与环比同比**：线性趋势（斜率 + 95%CI + R² + p）、Mann-Kendall 趋势检验、Cochran-Armitage 率的时间趋势检验、环比 / 同比变化表

注意：宽表（时间在列上）需先在「🧹 数据准备 → 🧩 宽表转长表」折叠后再使用本页。

### 4. 📈 描述性分析

- **数值变量**：样本量、均值、标准差、中位数、四分位数、正态性检验、直方图、Q-Q 图、箱线图
- **分类变量**：频数、比例、分布图

系统会根据正态性结果给出描述统计与组间检验建议，但仍需结合研究设计判断。

（原「相关分析」子页签已移到「🔬 统计推断」——它输出 r 与 p 值，属于推断而非描述。）

### 5. 🔬 统计推断

- **数值变量 × 分组**：t 检验、Welch t 检验、Mann-Whitney U、单因素方差分析、Kruskal-Wallis
- **分类变量 × 分组**：卡方检验、Fisher 精确检验
- **配对样本**：配对 t 检验、Wilcoxon 符号秩检验
- **相关分析**：Pearson、Spearman 或自动选择；给出相关系数热图（多变量）与两变量相关的 r、R²、p 值与散点图
- **一致性分析（Kappa / ICC / Bland-Altman）**：
  - 分类一致性：Cohen's Kappa（未加权 / 线性加权 / 平方加权），给出 Kappa、95%CI、一致性强度与交叉表
  - 数值一致性：ICC(2,1) 绝对一致性、ICC(3,1)、F 检验，置信区间用 Bootstrap 估计
  - Bland-Altman：平均偏倚、95% 一致性界限（LoA）、超界比例、比例偏倚回归与配对图
- **多重比较校正（FDR / Tukey HSD）**：两种用法
  - **已有一组 p 值做校正**：输入若干 p 值，选择方法（FDR-BH、FDR-BY、Bonferroni、Holm、Šidák），输出校正后 p 值及是否仍显著
  - **多组 Tukey HSD 两两比较**：选择数值变量与 ≥3 个水平的分组变量，直接给出全部两两比较的均值差与 95%CI 区间图
  - 用于多组两两比较，或同一批数据上同时检验多个指标时控制假阳性 —— 不做校正会使 p 值膨胀
- 结果可一键「✍️ 让 AI 写这段结果」转成论文段落

### 6. 🤖 预测建模

- **多重线性回归（连续结局）**：回答「哪些因素与某个连续指标独立相关」（住院天数、住院费用、各项评分）。这是最常规的回归类型 —— 在此之前程序只有 Logistic（二分类结局）与 Cox（时间-事件），连续结局只能被迫二分类，损失信息
  - 结局必须是数值型；自变量可多选，**把分组变量也选进来就是 ANCOVA**（校正基线后比较组间差异）
  - **系数表**：回归系数 β、标准误、t 值、p 值、95% 置信区间，以及**标准化 β**（用于比较不同量纲自变量的相对重要性）
  - **模型整体**：R²、调整 R²、F 检验及其 p 值、残差标准误、有效样本量，并写明剔除缺失的例数
  - **共线性诊断（VIF）**：每个自变量一个值，≥ 5 需留意、≥ 10 说明系数不稳定
  - **残差假设检验**：Durbin-Watson（自相关）、Breusch-Pagan（异方差）、结局偏度
  - **残差诊断图**：Q-Q 图、残差-预测值图、残差分布直方图
  - **可疑观测点**：按标准化残差、Cook's D、高杠杆值识别离群点与强影响点，列出实测值、预测值、残差与判定依据
  - 分类自变量自动展开为哑变量，**第一个水平作参照**并在结果中写明「参照水平 = ×××」
  - 系数表可导出 CSV；结果需点「📥 加入报告」才收录（含残差诊断图）
- **Logistic 回归**：系数表、OR、Pseudo R²、AUC（训练 / 测试）、ROC、校准曲线、决策曲线、列线图、Hosmer-Lemeshow 拟合优度；
  下方附 **最佳截断值（诊断效能）**：并列给出三种常用判据（约登指数最大 / 灵敏度≈特异度平衡点 / 离左上角最近）的推荐阈值，
  以及各阈值完整指标表（含混淆矩阵），可下载 CSV。注意截断值基于当前数据集的预测概率估计，若模型在同一数据上拟合会偏乐观，建议结合测试集或外部验证确认
- **Cox 生存回归**：需要生存时间（>0）与事件列（0/1），给出 C-index、AIC、系数表与 KM 曲线
- **LASSO 筛选 + Bootstrap 内部验证**：
  - LASSO（L1 正则）按交叉验证选择正则强度，压缩到 0 的变量被剔除
  - K 折交叉验证 AUC（均值 ± 标准差）
  - Bootstrap 内部验证：表观 AUC、平均乐观度、**校正后 AUC** 与泛化 AUC 的 95%CI
- **剂量-反应（限制性立方样条）**：选择连续暴露与结局（连续或 0/1）、节点数（默认 4）、可选协变量与参考点；
  输出**整体关联 p**、**非线性 p**、相对参考点的效应曲线（二分类给 OR）与 95%CI 图。
  非线性 p ≥ 0.05 时可按线性关系解读；p < 0.05 说明存在阈值 / 饱和 / J 型等非线性形态
- **外部验证（第二个数据集）**：先在当前数据上拟合 Logistic 模型，再把同一套系数与编码规则应用到**另一个独立数据集**；
 上传验证集 Excel（与训练集结构相同，可选 Sheet、表头行数与跳过行数，支持预览）后，输出内外部 AUC 对比、两条校准曲线、Brier 分数与预测概率分布图。
 为保证编码规则可移植，预测变量只支持「数值型」与「二分类」。内部验证只反映数据内部稳定性，**外部验证才能说明模型换了环境还能不能用**
- **重复测量（LMM / GEE）**：适合「同一对象被反复测量」的数据（一行 = 一个对象的一个时间点）。选择个体标识列、数值型时间变量、结局变量与可选协变量（原先在「⏱️ 时间与质控」页，属建模方法，已归到这里）：
  - **线性混合效应模型（LMM）**：随机截距模型，输出固定效应系数、p 值与 **ICC**（组内相关系数：越大说明个体间差异越重要，越有必要用重复测量模型而非普通回归）
  - **GEE 广义估计方程**：使用稳健标准误，对相关结构假设不敏感；可选分布族（Gaussian 连续 / Binomial 二分类输出 OR / Poisson 计数输出 RR）与相关结构（可交换 / AR(1) / 独立 / 非结构化）。相关结构不确定时先用「可交换」；AR(1) 在部分数据上不收敛（程序会提示），改用可交换后结论通常一致
  - 时间效应系数表示**每经过 1 个时间单位**结局的平均变化量；两者都不要求每个对象的测量次数相同，适合随访不均衡的数据。适合 ≥3 个时间点，配对 t / Wilcoxon 只能比较两个时间点
- **时间序列预测**：按数据行顺序作为时间先后，预测未来若干期（如未来 3–6 个月的例数或发生率）。可选指标列、时间标签列（仅用于图轴）、预测期数与方法（ARIMA 自动选阶 / Holt / Holt-Winters，后者需填季节周期）；
  程序自动把**最后 20% 时间点留出做验证**，与「朴素法（下期 = 本期）」基准比较并给出各方法误差对比表 —— **若所选模型还不如朴素法，说明该序列缺乏可利用的趋势或周期**，此时预测值仅供参考；同时输出平稳性检验、95% 预测区间与可下载的预测结果 CSV

**关于「跑完要再点一下收录」**：本页所有建模方法（以及各分析页）现在都**只显示结果、不自动写入报告**，需要写进报告的那一条点结果下方的「📥 加入报告」。另外，建模结果会**保存在会话里**：跑完之后再点页面上任何控件（包括收录按钮）结果都不会消失，不必重跑。

### 7. 📚 论文辅助

- **基线特征表（Table 1）**：选择分组变量后自动生成，是论文常规的第一张表。数值变量按正态性自动选择 `mean ± SD` 或 `median [IQR]`，
  并匹配 Welch t 检验或 Mann-Whitney U；分类变量自动在卡方与 Fisher 精确检验之间切换；多组时给出总体 p 值，
  并附 **SMD**（标准化均数差：|SMD| < 0.1 常视为组间平衡良好，且不受样本量影响）。结果表可导出 CSV
- **倾向性评分匹配（PSM）**：含 SMD 表与 Love plot
- **IPTW 逆概率加权**：选择 0/1 处理变量、结局（连续或 0/1）与协变量，指定权重类型（ATE / ATT / ATM）、权重截断分位、Bootstrap 次数；
  输出加权后效应（连续结局给平均处理效应差值，二分类结局给风险差 / 风险比 / 优势比及其 95%CI）、
  有效样本量 ESS、加权前后最大 |SMD| 与 Love plot
- **亚组分析森林图**、**敏感性分析（E-value）**

### 8. 📄 报告导出

**只有你点过「📥 加入报告」的结果才会进入报告缓存**（同名章节自动覆盖，不会重复堆积）。这是**有意设计**：分析页大多是「选完变量就出结果」，若自动收录，光是把页签浏览一遍报告里就会多出十几章你没主动要的内容（实测：浏览 8 个页签会从 1 章涨到 11 章）。进入该页后可：

1. 选择**报告语言**（中文 / English）
2. 修改**报告标题**（英文报告建议填英文标题）
3. **勾选要导出的章节**（默认全选）—— 同一份数据做多个课题时，可只选本次需要的
4. 选择**导出格式**，点「生成导出文件」，然后下载

**🌐 报告语言**：

选 English 后，导出的 Word 报告会切换为英文：章节名（按固定术语表翻译）、表/图题注（`Table 1` / `Figure 1`）、生成时间与落款。

三点说明：

- **表格表头也会翻译**：术语表覆盖常用表头（变量 → Variable、特征 → Characteristic、P 值 → P value、均值 → Mean、中位数 → Median 等）
- **变量名保持原样**：中文列名不会自动翻译（机器翻译医学变量名风险高）。需要英文变量名，请在导入数据前把列名改成英文
- **方法学段落目前只有中文版**：投英文期刊时可借助「AI 写作」选英文，把它转成英文表述
- 术语表中未收录的表述会保留原文，**不会猜译**（宁可中英混排，也不出现错误的统计术语）

| 格式 | 内容 | 适用 |
| ---- | ---- | ---- |
| **📄 Word 报告** | 统计表格排成**三线表**（顶线与底线加粗、表头下细线、无竖线），插图为 300 dpi，宽图自动铺满正文宽度 | 直接投稿或作为附件 |
| **📊 Excel 结果表** | 每个含表格的章节一个工作表，**保留原始数值**（不套用展示格式） | 审稿人复核、二次计算 |
| **🖼️ 图片包 ZIP** | 每张图的 300 dpi PNG + TIFF（写入 dpi 元数据、LZW 无损压缩），并附「图目录.txt」 | 期刊要求单独上传图片文件时 |

数字格式已按论文惯例处理：整数原样、小数保留三位并去掉多余零（`1.080` → `1.08`）、p 值小于 0.001 写作 `<0.001`、缺失写 `—`。

**📐 表格样式（期刊模板）**：

不同期刊对三线表的线宽、字体、字号、小数位要求不同。展开「📐 表格样式（期刊模板）」可选择：

| 模板 | 特点 |
| ---- | ---- |
| 中文期刊（默认） | 宋体；顶/底线 1.5 pt、表头线 0.75 pt；表头 10 pt 加粗、表体 9 pt |
| SCI 英文期刊 | Times New Roman；顶/底线 1.0 pt、表头线 0.5 pt；9 pt |
| 更细线条 | 顶/底线 1.0 pt、表头线 0.5 pt |
| 表头不加粗 | 表头与表体同为常规字重 |
| 自定义（手动设置） | 线宽、字号、字体、表头是否加粗、小数位均可调 |

**数字格式按列名语义处理**（不再全局一刀切）：

- **p 值列** → 固定小数位，极小值写作 `<0.001`（阈值随小数位联动）
- **百分比 / 构成比列** → 1 位小数
- **计数列**（n / 例数 / 频数 / 样本量）→ 取整
- 其余数值 → 按模板设定的小数位并去掉多余零（`1.080` → `1.08`）

列名歧义已处理：`PaO2/FiO2 (mmHg)` 虽以 P 开头，但不会被当成 p 值列。

**图注编号与图片宽度**（导出时生效，改完立即有用）：

- **自动编号**：报告里的表格依次加「表 1 / 表 2…」题注（在表格**上方**），插图依次加「图 1 / 图 2…」题注（在图片**下方**），均为期刊惯例排法；不需要编号可取消勾选
- **图片宽度**：期刊常按单栏（约 8.5 cm）或双栏（约 17 cm）要求，可在此指定；填 0 表示按图片宽高比自适应

**图片内字体与字号**（绘图时生效）：选择模板时会同时应用对应的图片样式（中文字体 / Arial、基础字号、标题字号、刻度字号、导出分辨率）。SCI 模板使用更小的字号与 Arial 字体。

> ⚠️ 注意：图片的字体与字号是在**绘图时**写入的，因此改动后需要**重新运行一次分析页**才会体现在图里；而图注编号与图片宽度是导出时才处理，改完立即有用。

**📝 方法学段落（自动汇总，写论文最省事的一步）**：

论文的「方法」部分必须交代缺失值如何处理、异常值是否排除、用了哪些检验以及选择依据。这一区块把这些信息从本次**实际执行过的处置**中自动汇总成草稿：

- 上方表格列出「样本量 / 缺失值 / 异常值 / 变量类型人工核定 / 统计方法」的本次做法；研究设计与检验水准可自行选择
- 「各类统计方法对应的分析」展开后，能看到每类方法是从哪个分析归纳来的
- 点「📥 把方法学段落加入报告」即可写入 Word（按**纯文本**写入，不会出现 Markdown 符号）

两条重要说明：

1. **只汇总真实做过的**：报告章节里没出现过的方法不会出现在草稿里（例如你没做 PSM，草稿就不会写倾向性评分），因此不会出现"方法里写了、结果里却没有"
2. **仍需通读核对**：草稿是按规范模板组织的通用表述，研究设计、纳入排除标准、变量定义与单位等需你补充；**缺失处理方式与检验选择依据尤其要确认与实际一致**

报告缓存属于当前浏览器会话，重新上传数据后会清空。

**📋 分析台账（回答「我做过哪些分析」）**：每次产出结果的分析都会自动记入台账，包含分析名、结论摘要、是否含表格与图、时间，可导出 CSV，也可一键加入报告（作为论文附录里的分析清单）。

台账与报告缓存是分开存储的，原因很实际：

| | 报告缓存 | 分析台账 |
| --- | --- | --- |
| 换数据时 | **清空**（旧结果确实不再适用） | **保留**，并插入「数据已更新」分隔标记 |
| 内容 | 章节正文、统计表格、插图 | 分析名、摘要、时间（体量很小） |
| 用途 | 导出 Word / Excel / 图片包 | 回溯「做过什么、基于哪版数据」 |

因此台账能看出**哪一段分析是基于哪一版数据做的**。这份清单也会随「AI 审阅与写作」一起发送，让 AI 写方法段落时有据可依，而不是靠章节标题去猜。清空台账时会一并清空报告缓存（两者记录的是同一批分析）。

**关于章节筛选（写论文时很关键）**：现在**不会**再有「你没主动选择过、却自动进了报告」的结果 —— 每条结果下方都有一个「📥 加入报告」，只有点过的才进报告。所以进入报告导出页时，章节列表里就是**你要写进报告的那些分析**。

- 分析页上：确认这次要写进报告的那条，点它下面的「📥 加入报告」
- 报告导出页：仍可用右侧的 🗑️ **移除**不需要的章节，或在上方「要导出的章节」中只勾选本次需要的（原始缓存保持不变）

下方「🤖 AI 审阅与写作（可选）」区块（配置 AI 后出现）：

- **🧑‍⚖️ 让 AI 审阅本次分析**：把已收集的结果章节交给 AI，检查方法是否适配、前提是否满足、结论与数值是否自洽、可能面临哪些审稿质疑；审阅意见可加入报告
- **✍️ 让 AI 写论文段落**：根据结果生成中文 / 英文「结果」或「方法」段落，可加入报告后一起导出

**关于流式输出**：所有 AI 调用都采用流式（边生成边显示），生成过程实时可见，不必对着转圈等待。这同时带来一个实际好处 —— 超时判定从「总耗时」变成「两条新内容之间的间隔」，本地模型首次加载模型权重（可能一两分钟）或长文生成都不会误判超时。

**关于本地模型（如内网 vLLM / Ollama / LM Studio）**：

- **免 Key**：只填服务地址与模型名即可，API Key 留空
- **自动绕过代理**：`127.0.0.1`、`localhost` 与内网段（`10.x`、`172.16–31.x`、`192.168.x`）的地址一律不走系统代理。否则公司网络里的 `HTTP_PROXY` 会把本机请求也转给代理，表现为「地址明明填对了却连不上」
- **模型名不用猜**：点「📋 列出可用模型」，程序读取服务的 `/v1/models` 并列出；vLLM 的 `--served-model-name`、Ollama 的 `qwen2.5:14b` 都能直接看到
- **地址写法随意**：`http://127.0.0.1:8000`、`.../v1` 都会自动补全为 `/v1/chat/completions`
- **服务未启动时的提示会直接告诉你去确认服务**，不会只说「请求失败」
- 若服务不提供 `/v1/models`（返回 404），程序会提示手动填写模型名

**AI 建议如何落地（它不会替你执行）**：

AI 只输出**建议**，程序不会自动跳转页面、不会自动填写参数、也不会自动运行任何分析 —— 方法与参数的最终决定权始终在你手上。为避免「AI 说的」与「程序算的」各说各话，界面会额外做两件事：

1. **与本地规则引擎并列对照**：把 AI 的方法建议与规则引擎的推荐逐条比对，分四类展示

   | 类别 | 含义 | 怎么处理 |
   | ---- | ---- | -------- |
   | ✅ 双方一致 | 两种判据都认为可做 | 可以放心做 |
   | 🆕 仅 AI 建议 | AI 提出了规则引擎未推荐的分析 | 看一眼是否漏掉了有价值的角度 |
   | 📋 仅规则引擎推荐 | 规则引擎认为可做、AI 未提及 | AI 可能只是没列全 |
   | ⚠️ 分歧 | **AI 认为可做，但规则引擎判定当前数据条件不足**（会列出缺什么条件） | 最需要你判断：可能是规则判据过严，也可能是 AI 没注意到某个硬约束 |

   两者不一致时由你决定听谁的 —— AI 更熟悉方法学，规则引擎更清楚这份数据实际具备什么。

2. **字段类型修正需你确认**：AI 若发现某列类型可能被误判（例如「随访月数」被判为日期，导致 Cox 选不到生存时间），会给出一条修正建议

   - 界面列出「字段 / 当前类型 / AI 建议改为 / 理由」，并标注哪些与当前一致（无需改动）
   - **必须勾选确认项后按钮才生效**；应用后与手动「🏷️ 变量类型调整」走完全相同路径，并在该区域留下应用记录便于追溯
   - AI 编造的字段名、或不在允许范围内的类型，会被程序**拒绝并明确列出**，不会静默应用

**AI 建议如何落地（一键配置）**：

AI 的方法建议会附带一份「▶️ 按 AI 建议一键配置」清单，点一下就会：

- **跳到对应页签**（如「⚖️ 统计推断」）
- **自动切到对应子面板**（如「数值变量 × 分组」）—— 用 `st.radio` 的页面（统计推断、预测建模、论文辅助）可以精确直达
- **预填变量与参数**：AI 在结构化清单里给出的变量会被采用；没给或类型不合适的，程序按角色启发式补一个（界面会分别标出「AI 指定」与「程序推测，请核对」）

三条边界：

1. **不代替你点运行**：回归、Table 1、外部验证这类需要点按钮的分析，跳转后不会自动执行
2. **但要注意**：部分页面本来就是「选定变量即出结果」（如组间比较、描述性统计），跳转预填后这一类会直接算一次，结果进入报告缓存与分析台账。如果参数不对，重新选择一次即可覆盖
3. **标签页无法自动切换**：「⏱️ 时间与质控」（5 个子标签）与「📈 描述性分析」（3 个子标签）用的是标签页结构，程序无法切换标签 —— 此时变量仍会预填，页面顶部会提示「请手动点开 ××× 标签」

跳转后会有一条提示条写明：本次配置了哪个分析、哪些变量是 AI 指定的、哪些是程序推测的、哪些没预填成功及原因。

**🧪 探索性分析（AI 多轮）**：

在「📊 总览与洞察」页，除了上面的 AI 分析建议，还有一个**多轮循环**入口：给一个研究问题，AI 会连续执行多轮分析 —— 自己从白名单里选方法、看结果、再决定下一步，最后给出结论。

```
你的问题：「哪些因素与住院天数独立相关？」
  轮 1  建议先做 Table 1 看基线均衡性     → 本地执行 → 结果回传
  轮 2  看到基线不均衡 → 建议多重线性回归  → 本地执行 → 系数表 + VIF 回传
  轮 3  判断信息已足够 → 给出结论与方法学段落
```

**适用范围要说清楚**：它适合**探索性分析**（"这份数据能看出什么"）；如果你要验证的假设已经确定，方法应当由研究设计决定，而不是让 AI 去试 —— 那种情况请用上面的「一键配置」。

**从建议直接进探索**：AI 分析建议给出的每条方法后面都有「🧪 探索」按钮 —— 点它会把该建议（方法名 + 涉及变量）连同你填过的研究问题一起**预填**到本面板。程序**不会**替你点开始：多轮分析会逐轮把统计结果发送给 AI，请核对后勾选确认项再启动；不合适就直接改上面的研究问题。（「📋 表格结构诊断 → 🔁 整理后评估」里给出的「建议的第一步」也有同样的入口，会跳到本页并把该建议填进来。）

**约束全部由程序强制，不依赖 AI 自觉**：

| 约束 | 说明 |
| --- | --- |
| 轮数上限 | 默认 6 轮，防止跑飞与成本失控 |
| 白名单执行 | AI 只能从 18 个预定义分析里选（Table 1 / 两组比较 / 相关分析 / 多重线性回归 / Logistic 回归 / Tukey 两两比较），不能自由构造统计过程 |
| 参数校验 | 字段必须真实存在且类型合适；**校验失败会把原因回告 AI 让它改正**，而不是由程序悄悄换一个变量 |
| 结果截断 | 发给 AI 的表格最多 12 行 × 12 列，**不含个体数据行**；图片不发送 |
| 多重比较提醒 | 连续执行 ≥3 个分析等于做了多次检验，程序会**强制**提示做多重比较校正 |
| 可回溯 | 每一轮的动作、参数与 **AI 的决策理由**都记入分析台账 |
| 结论定性 | 最终结论标注为「AI 整理的说明，**不是统计结论**」 |

**AI 可执行的 18 个分析**：

| 类别 | 分析 |
| --- | --- |
| 描述与基线 | 基线特征表（Table 1）、相关分析 |
| 组间比较 | 两组比较（数值）、多组比较（ANOVA / Kruskal-Wallis）、分类变量比较（卡方 / Fisher）、配对比较、多组两两比较（Tukey HSD） |
| 回归建模 | 多重线性回归、Logistic 回归、Cox 比例风险回归、剂量-反应（限制性立方样条） |
| 重复测量 | 线性混合效应模型（LMM）、GEE 广义估计方程 |
| 因果推断 | 倾向性评分匹配（PSM）、IPTW 逆概率加权、亚组分析（森林图） |
| 一致性 | Kappa、ICC / Bland-Altman |

每个分析在面板的「📋 AI 可执行的分析」里都能看到用途说明。**需要特殊数据结构的分析（如 LMM / GEE 需要同一对象多次测量）若数据不满足，程序会明确报错并把原因回告 AI**，它会据此换方法。

使用时需要勾选一次确认（多轮分析会发送各轮的统计结果表）。AI 的判断依据仅限「你已完成的各轮结果」，不会自行编造数值。

**隐私边界（重要）**：

- 只发送 **L1 结构摘要**：字段名、类型、唯一值数、缺失率、结构角色；**不含任何个体数据行，也不含均值 / 频数等数值统计**
- 发送前可**逐字预览**将发送的全部内容（所见即所发），摘要 JSON 可下载留档
- 程序在发送前做安全自检，若载荷中混入数据行会直接拒绝发送
- 启用后侧边栏底部提示会由「完全本地处理，数据零外传」变为「本地计算 + AI 解读已启用」；启用即意味着这部分内容离开本机，请按所在机构的数据管理规定决定是否使用
- 未配置 AI 时，所有 AI 入口只显示一行引导提示，本地功能完全不受影响；调用出错（Key 无效、余额不足、网络不通、超时）会给出中文提示

## 六、结果解释注意事项

- 软件结果用于辅助分析，不能替代医学判断和统计学审查。
- 正态性检验、方差齐性和样本量会影响检验方法选择。
- 相关关系不等于因果关系。
- 多组两两比较或同时检验多个指标时应做**多重比较校正**，否则假阳性率会升高；校正后仍需结合临床意义解读。
- PSM、回归和亚组分析仍可能受到未测量混杂影响。
- 建模结果应检查缺失值、异常值、共线性、样本量和模型稳定性。
- 内部验证（交叉验证 / Bootstrap）不能替代外部验证；若模型将用于其他机构或人群，应做外部验证并报告校准情况。
- 重复测量数据应使用混合效应模型或 GEE，普通回归会低估标准误、放大假阳性。
- 时间序列预测依赖「历史模式延续」的假设；若留出验证显示不如朴素法，说明该序列缺乏可利用的模式。
- **AI 输出仅供参考**：方法前提、变量含义与结论需自行核对；所有数值结果以本地计算结果为准。
- 控制图与趋势检验反映的是数据中的时间模式，判读仍需结合临床实际与流程变化。
- 导出报告前应核对变量含义、分组编码、样本数和统计方法。
- 患者数据应遵守所在机构的数据安全和隐私管理规定；导出或对外发送前建议先做脱敏。

## 七、常见问题

### 每次启动都提示「是否允许访问网络」？

这是历史版本的问题：早期配置把服务地址绑定为 `0.0.0.0`（监听所有网卡，原本是为服务器 + 反向代理部署准备的），单机运行时会触发 Windows 防火墙弹窗。

当前版本已改为**只监听 `127.0.0.1`** 并关闭 Streamlit 匿名使用统计，正常情况下不再弹窗。如果仍出现提示（旧的防火墙规则残留）：

1. 可以直接点「取消」，不影响使用（程序只在内存中本机通信）；
2. 或在「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」中，删除名为「医析台」的旧规则。

### 双击后没有打开浏览器？

先等待 30–60 秒，首次启动需要解包和加载科学计算库。也可以手动打开：

`http://127.0.0.1:8501`

- 若 8501 打不开：说明端口被占用，程序会自动改用 8502 或更高端口，实际地址记录在 `%USERPROFILE%\医析台端口.txt`
- 若双击后**完全没有反应**：通常是检测到已有实例在运行（程序会提示并复用该实例），先关闭浏览器里已打开的页面再试

### 上传后显示「当前没有任何数值变量」/ 分析页没有可选项？

通常是因为表格结构与分析型数据不同，按顺序检查：

1. 侧边栏「⚙️ 导入设置」里的**跳过开头行数**是否正确（报表大标题会导致列名变成「Unnamed: 1」）；
2. 到「📊 总览与洞察 → 🏷️ 变量类型调整」把需要的字段指定为「数值」；
3. 若时间是横向铺开的列（1月…12月），先做「🧩 宽表转长表」；
4. 再看「📊 总览与洞察」里各条推荐的阻塞原因与判据。

### 上传后列名全都一样（或出现「标题_1、标题_2…」）？

说明报表顶部的**大标题行被当成了字段名**。程序现在会自动检测这种情况，并在「📊 总览与洞察」页给出提示。

修正方法：在侧边栏「⚙️ 导入设置 → **跳过开头行数**」填入大标题占用的行数（通常是 1），再点「🔄 重新解析该 Sheet」。

### 提示缺少 Excel 读取引擎 / 加载失败？

说明程序包不完整（早期版本漏打包 `xlrd`、`openpyxl`）。请使用当前版本，它已内置这两个引擎；如需自行打包，使用根目录的 `打包.py`，其中已显式声明这些依赖。

### 某个分析方法不可用？

通常与变量类型、分组数量、缺失值或有效样本量有关。先看「总览与洞察」的推荐阻塞提示与字段元数据，再检查对应变量的编码和有效观测数。

### 中文 CSV 打开乱码？

使用 Excel 的「数据 → 从文本 / CSV」导入并选择 UTF-8 编码；当前导出文件已包含 UTF-8 BOM，通常可直接双击打开。

### PSM 和 IPTW 该用哪个？

两者都用于控制**可测量的**混杂，选择依据是数据规模与展示需要：

| 维度 | PSM（倾向性评分匹配） | IPTW（逆概率加权） |
| ---- | --------------------- | ------------------ |
| 样本使用 | 只保留匹配上的样本，损失样本量 | 保留全部样本，统计效率更高 |
| 直观性 | 成对匹配、流程直观 | 靠权重，需看平衡诊断 |
| 主要风险 | 匹配后样本代表性下降 | 极端倾向评分导致大方差（可用截断分位或 ATM 权重缓解） |

经验上：样本量较大、事件数较多时优先 IPTW；样本量较小、需要直观展示匹配过程时用 PSM。
无论用哪个，都要报告加权 / 匹配后的平衡诊断（|SMD| < 0.1），并说明协变量是研究设计阶段预先确定的。

### AI 功能怎么开启？API Key 安全吗？

在侧边栏展开「🤖 AI 解读（可选）」，填入服务地址、API Key 与模型名，点「🔌 测试连接」确认连通即可使用。

- Key 默认**只存在于当前会话**，不写入磁盘；只有勾选「记住到本机」才会保存到用户目录的配置文件（**明文**）
- 该文件可随时用「🗑️ 清除本机配置」一键删除
- 只发送数据结构摘要（字段名、类型、唯一值数、缺失率、结构角色），不含个体数据行与数值统计，且发送前可逐字预览
- 若所在机构规定数据不得外传，请勿启用；或把服务地址指向内网自建的 vLLM / Ollama（数据不出内网）

### AI 提示「连接失败 / 余额不足 / 超时」？

| 提示 | 常见原因与处理 |
| ---- | -------------- |
| 401 / 403 | Key 无效或没有该模型权限：核对 Key 与模型名是否匹配 |
| 404 | 服务地址填错：一般填到域名或 `.../v1` 即可，程序会自动补 `/chat/completions` |
| 余额不足 / 额度用尽 | Key 有效但账户没额度：需充值或更换服务 |
| 超时 | 在侧边栏把「超时」调大（流式下最长间隔可设到 3600 秒）；本地模型首次加载或推理较慢时调大 |
| 无法连接（本地服务） | 确认服务已启动（vLLM / LM Studio 已运行、Ollama 在后台），并核对端口。程序已自动绕过系统代理，不必手动配置 |
| 请求被拒（400） | 多为模型名不符：点「📋 列出可用模型」从服务返回的清单里选，避免手打错 |
| 流式响应无内容 | 该服务可能不支持流式输出，换用其他模型或改用支持流式的部署方式 |

以上问题都**不影响本地统计分析功能**，可继续在不启用 AI 的情况下使用。

### 改坏了数据能退回吗？

可以。到「🧹 数据准备 → ↩️ 回到上一步」展开，会显示「可回退 N 步」与最近一步撤销的是什么操作，点「↩️ 回到上一步」即可退回。变量类型指定、表格整理、**清洗**、插补、多表关联、以及换数据（重新上传 / 切换 Sheet）之前的状态都会自动存为回退点，最多 8 步。（「应用清洗」此前是唯一没有回退点的数据变更，现已修正。）

- 数据、人工类型指定与导入设置会**一起回退**，否则退回后下一次刷新会立刻按旧设置重新解析
- 分析类操作是只读的，不需要回退
- 每层回退点是一份完整的数据副本，界面会显示占用的内存；数据很大时建议及时清空历史

### 如何重新开始一次分析？

重新上传文件或切换 Sheet。系统会更新当前数据、结构画像与分析结果缓存 ——
注意**切换 Sheet 会清空已收集的报告章节**（报告是跟着「当前这份数据」走的）；分析台账会保留，并插入一条数据变更标记。

### 一个 Excel 里有多个 Sheet，能一起分析吗？

**不能把多个 Sheet 直接合并成一份数据分析** —— 程序一次只加载一个 Sheet（侧边栏「Sheet」下拉选择），
且切换 Sheet 会清空已收集的报告章节。可行的做法：

| 你的情况 | 建议做法 |
| -------- | -------- |
| 各 Sheet 互相独立（如一年一个 Sheet） | **逐个 Sheet 分析**：切到某个 Sheet 跑完、导出该份报告，再切下一个。台账会记下每次数据变更，事后能看出哪段分析基于哪份数据 |
| 各 Sheet 是同一张表的不同部分（按科室 / 按年份拆开） | **先在 Excel 里纵向合并**成一张表再上传，并补一列「来源」标明出处 —— 程序里的分组比较、筛选、回归都能直接用这一列做分析 |
| 各 Sheet 是同一批对象的不同指标 | **先在 Excel 里按个体标识横向合并**（VLOOKUP / XLOOKUP），再上传 |
| 想用 Sheet A 建的模型去验证 Sheet B | 直接可用：「🤖 预测建模 → 外部验证」支持上传第二个数据集（可选 Sheet），输出内外部 AUC 对比、校准曲线与 Brier 分数 |


## 八、目录说明

**源码目录（仓库）：**

| 文件或目录         | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| `app.py`           | 应用主入口（Streamlit 界面与全部页签）                        |
| `modules/`         | 分析功能模块（描述统计、推断、建模、AI 解读等 30+ 个）         |
| `sample_data/`     | 示例数据（300 例演示数据，可直接试用）                        |
| `.streamlit/`      | 运行配置（默认只绑本机、关闭使用统计）                        |
| `docs/`            | 文档：使用说明、服务器部署说明、界面截图                      |
| `scripts/`         | 打包与自检脚本（打包 / 单文件启动器 / 自检 / 依赖体检 / 生成说明文档） |
| `requirements.txt` | 运行依赖清单                                                 |
| `app.ico`          | 程序图标                                                     |
| `CHANGELOG.md`     | 更新日志（按版本记录新增功能与修复）                          |

**打包产物（可重新生成，不纳入版本管理）：**

| 文件或目录   | 说明                                                        |
| ------------ | ----------------------------------------------------------- |
| `医析台.exe` | 用户实际运行的单文件程序（位于 `dist_single/`）              |
| `dist/`      | onedir 版程序目录（`医析台.exe` + `_internal/`），可直接运行 |
| `_internal/` | 运行时库目录（打包产物依赖，勿手动删除）                     |

普通使用时只需要保留并运行 `医析台.exe`。
